# Karina Kandatyan

Персональный сайт клинического психолога, КПТ-терапевта и коуча ICF Карины Кандатьян.

Главное действие сайта — переход на практический курс «Тревожность и неопределённость». Также доступны запись на личную консультацию и профессиональные социальные сети.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Проверка production-сборки:

```bash
pnpm build
```
